# Bohemian Flow AI — Brand Guidelines

**Last Updated:** April 2026

---

## Brand Overview

Bohemian Flow AI is an AI consultancy specializing in automation, lead generation, and intelligent workflows. The brand identity reflects sophistication, technical innovation, and forward-thinking problem-solving.

The logo combines a **geometric node/flow icon** (representing automation and connected systems) with a **bold, modern wordmark** (representing clear communication and expertise).

---

## Brand Palette

### Primary Colors

| Color | Hex Code | Usage |
|-------|----------|-------|
| **Brand Orange** | `#F5A800` | Icon mark, accents, primary visual element |
| **Deep Navy** | `#0D1F3C` | Primary background, text on light backgrounds |
| **White** | `#FFFFFF` | Text on dark backgrounds, negative space |
| **Ghost Grey** | `#EBEBEB` | Secondary text, watermark effects, subtle elements |

### Color Combinations

- **Primary:** Deep Navy background + White text + Orange accents
- **Inverse:** White/Light background + Navy text + Orange accents
- **Accent:** Use Orange sparingly for call-to-action, emphasis, or highlighting key elements

## Logo Variants & Usage

### 1. **Primary Wordmark** (Dark Background)

**Usage:**
- Main brand applications (website header, letterhead, presentations)
- Social media cover images
- Email signatures and templates
- Printed materials with dark backgrounds

**Best Practice:** Use on dark navy (`#0D1F3C`) or solid dark backgrounds for maximum contrast.

---

### 2. **Full Wordmark** (Light/Transparent Background)

**Usage:**
- Overlays on colored or patterned backgrounds
- Web banners and hero sections
- Marketing materials on varying backgrounds
- Flexible placement in document headers

**Best Practice:** Verify sufficient contrast between the logo and background. Works on light, medium, and bold color backgrounds.

---

### 3. **Icon Mark Only**

**Usage:**
- Website favicon (16px, 32px, 64px sizes)
- Mobile app icons
- Social media profile pictures (square format)
- Small UI elements (buttons, badges, tabs)
- Minimal branding in tight spaces

**Best Practice:** Minimum size of 100px for clarity. Works on white or light backgrounds.

---

### 4. **BF Stacked Monogram** (Vertical Layout)

**Usage:**
- Square layouts (social media post backgrounds)
- App icon variations
- Icon badges or secondary branding
- Compact branded assets

**Best Practice:** Use on white/light or solid color backgrounds. The faint "BF" text adds depth for larger applications.

---

### 5. **BF Horizontal Monogram** (Side-by-Side Layout)

**Usage:**
- Horizontal compact branding
- Side margins or corner placements
- Partner/integration logos
- Signature elements in designs

**Best Practice:** Similar contrast rules to the stacked monogram. Reserve for compact layouts where full wordmark won't fit.

## Typography

### Primary Typeface
- **Name:** Rajdhani Bold or Exo 2 Bold (or similar rounded geometric sans-serif)
- **Usage:** Wordmark, headings, brand-forward messaging
- **Characteristics:** Geometric, bold, confident, modern

### Recommended Body Fonts
- **Inter** (web/digital)
- **Roboto** (fallback)
- **Montserrat** (headings in marketing materials)
- **System fonts** (clean sans-serif: -apple-system, Segoe UI)

### Typography Hierarchy

| Level | Font | Size | Color | Usage |
|-------|------|------|-------|-------|
| H1 | Rajdhani Bold | 48–64px | Navy or Orange | Main headlines |
| H2 | Rajdhani Bold | 32–40px | Navy | Section headers |
| H3 | Roboto Bold | 24–28px | Navy | Subheaders |
| Body | Roboto Regular | 16px | Navy | Default text |
| Small | Roboto Regular | 12–14px | Ghost Grey | Captions, secondary text |

## Logo Clear Space & Sizing

### Minimum Clear Space
Maintain a clear space of **at least the width of the icon mark** around the logo on all sides. This prevents visual clutter and ensures the logo stands out.

### Minimum Size
- **Digital/Web:** 100px width minimum
- **Print/Large Format:** 1 inch (2.54cm) width minimum
- **Favicon/Small UI:** 32px minimum (icon mark only)

### Recommended Sizes
- **Website Header:** 200–300px width
- **Email Signature:** 150–200px width
- **Social Media Profile:** 400px square (icon) or 800px × 200px (horizontal)
- **Business Card:** 50–80px width

## Usage Guidelines

### ✓ DO

- Use the logo as provided without modification
- Maintain clear space around the logo
- Use the full wordmark for primary branding on all touchpoints
- Reserve the icon mark for small formats (favicon, app icons)
- Use white text on dark navy backgrounds for maximum contrast
- Place the logo on solid, simple backgrounds
- Scale the logo proportionally (never stretch or squeeze)
- Use the orange accent color for call-to-action and emphasis

### ✗ DON'T

- Rotate, skew, distort, or otherwise transform the logo
- Change the brand orange color (keep `#F5A800` exact)
- Alter the proportions of the icon or wordmark
- Place the logo on backgrounds with insufficient contrast
- Reduce the logo below 100px width without approval
- Add effects (shadows, glows, gradients) to the logo
- Use the logo on complex or busy backgrounds
- Mix logo variants on the same page without clear visual separation
- Create new variations of the logo without design approval

## Brand Color Applications

### Primary Application: Dark Navy + Orange
Bohemian Flow's core identity combines deep navy (professional, stable, trustworthy) with vibrant orange (creative, energetic, forward-thinking). Use this combination as the default for:
- Website design
- Email templates
- Presentation slides
- Marketing materials
- Product interfaces

### Secondary Application: White + Navy + Orange
For light-background contexts:
- Use Navy as primary text
- Use Orange for links, buttons, and accents
- Use White for clean background separation

### Accent Applications
Reserve orange for:
- Call-to-action buttons
- Links and hover states
- Key statistics or highlights
- Icon badges
- Emphasis text (no more than 10–15% of page content)
